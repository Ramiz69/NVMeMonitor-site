NVMe Monitor 支援

請告訴我們你當時想做什麼，以及發生了什麼問題。如有需要，請附上 Mac 機型、macOS 版本，以及 SSD 與外接盒型號。

寄信聯絡支援 · support@nvmemonitor.app

支援哪些磁碟機？

NVMe Monitor 需要 macOS 27 或以上版本，以及 macOS 能辨識為原生 NVMe 的外接 SSD。相容的 Thunderbolt 或 USB4 外接盒可透過 PCIe 存取控制器。即使 Finder 能開啟檔案，部分外接盒也無法提供 SMART 資料。

找不到磁碟機或看不到 SMART 資料

  1. 在「磁碟工具程式」中確認 SSD 有顯示為實體磁碟。
  2. 如果外接盒支援，請使用合適的 Thunderbolt 或 USB4 連接線直接連接 Mac。
  3. 在 NVMe Monitor 中選擇「更新」。若曾手動選擇的磁碟機已重新連接，請在「設定」→「監控」中再次選取。

通知與溫度單位

在「設定」→「警示」中開啟通知，並在 macOS 中允許通知。在「設定」→「監控」中，可選擇攝氏、華氏或依系統設定顯示。

選擇性分享診斷資料

前往「設定」→「支援與隱私權」，即可預覽或清除本機的 MetricKit 報告。若想分享報告，請選擇「附加 MetricKit 診斷資料」。在郵件草稿中輸入支援信箱，寄出前請確認內文與附件。

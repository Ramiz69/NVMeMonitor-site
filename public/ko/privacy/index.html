개인정보 처리방침

배포자: Ramiz Kichibekov

NVMe Monitor는 외장 SSD의 측정값을 사용자의 Mac에서 처리합니다. 배포자나 제3자에게 자동으로 전송하지 않습니다.

드라이브 정보와 환경설정

앱은 모델, 연결 유형, 용량, 현재 macOS 디스크 식별자 같은 장치 정보와 SMART 온도, 경고, 오류, 사용량 카운터를 읽습니다. 드라이브의 파일을 열거나 일련번호 및 SMART 측정 이력을 저장하지 않습니다. 환경설정, 경고 상태, 부팅 세션 식별자는 선택을 복원하고, 중복 경고를 방지하고, 드라이브 연결을 구분하기 위해 Mac에 저장합니다.

선택 사항인 MetricKit 진단

macOS는 성능 보고서와 충돌 또는 응답 중단 추적 기록 같은 기술적 진단 정보를 제공할 수 있습니다. 앱은 여기에 드라이브 측정값, 식별자 또는 환경설정을 추가하지 않습니다. 최근 7일간의 보고서를 최대 5개까지 Mac에 저장합니다. 설정 → 지원 및 개인정보 보호에서 보고서를 미리 보거나 삭제할 수 있습니다. 첨부용 임시 사본은 이후 앱 실행 시 또는 보고서를 삭제할 때 지워집니다. 메일 앱에서 저장하거나 보낸 사본은 별도로 관리됩니다.

지원 이메일

이메일 작성 기능은 앱과 macOS 버전이 포함된 수정 가능한 초안을 열며 받는 사람은 비어 있습니다. 진단 JSON 파일은 사용자가 선택했을 때만 첨부됩니다. 보내기 전에 확인하거나 제거할 수 있습니다. 앱은 이메일을 보내거나 보고서를 업로드하지 않습니다. 메일 앱에서 파일이 첨부되지 않으면 로컬 사본을 직접 첨부할 수 있습니다. 배포자는 사용자가 공유하기로 한 정보를 문의에 답하고 문제를 조사하는 데 사용합니다.

알림 및 로그인 시 실행

알림을 허용하면 macOS가 전달과 표시 여부를 관리합니다. 알림에는 드라이브 모델과 해당 측정값 또는 경고가 표시될 수 있습니다. 로그인 시 실행은 선택 사항이며 macOS가 등록을 관리합니다.

수집, 보관 및 사용자의 선택

앱은 계정을 요구하지 않으며 광고, 추적 또는 분석을 사용하지 않습니다. 사용자 데이터를 판매하지 않습니다. 환경설정과 경고 상태는 업데이트되거나 삭제될 때까지 Mac에 남습니다. 알림 권한 취소, 전달된 알림 지우기, 로그인 항목 삭제는 macOS에서 할 수 있습니다. 저장된 환경설정과 경고 상태를 지우려면 앱을 제거할 때 로컬 앱 데이터도 삭제하세요.

웹사이트 및 지원 서비스

Cloudflare는 이 사이트를 호스팅하고 사이트를 제공하고 보호하는 데 필요한 연결 정보를 처리합니다. 사이트는 광고나 분석 스크립트를 사용하지 않습니다. 지원 이메일은 Cloudflare Email Routing을 통해 배포자의 Gmail 받은편지함으로 전달됩니다. 각 서비스 제공자는 메시지와 첨부 파일을 전달하고 저장하기 위해 처리합니다.

사이트의 화면 모드와 온도 단위 설정은 브라우저에 저장됩니다.

개인정보 보호에 관해 궁금한 점이 있거나 이메일로 공유한 정보의 삭제를 요청하려면 문의해 주세요. support@nvmemonitor.app
